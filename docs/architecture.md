# 技术架构
建议 Astro + TypeScript 静态站点，中文全文搜索使用 Pagefind；本阶段不安装依赖。静态部署便于 Mac 维护并避免运营数据库。

数据层分离原始来源元数据、标准化实体、译名映射、发布产物。实体使用稳定 ID，不以中文显示名作为键。以用户提供的英文 Wiki 为内容基准，逐页记录 source_url、revision_id、synced_at，并分别存储本体/DLC、来源明确标注的游戏版本及翻译 CSV 提交。Wiki 各页可能更新不同步，不推定全站具有统一游戏版本；不要求 Switch 版本核验。

采集器仅在授权门禁通过后启用：显式白名单、低并发、缓存、maxlag、429/503 停止与退避、增量修订检测。模板变化须触发依赖实体重建。发布前检查来源及授权证据，缺失即失败。
